## 已修复的问题

### 🔴 P0 问题（已在 5/20 重构中修复）
1. **心跳字节序不一致** - HeartbeatSenderService 已统一使用主机字节序
2. **鉴权中间件是死代码** - MessagePipeline 已接入 HandleClient
3. **目录心跳不校验签名** - HeartbeatHandler 已实现签名校验
4. **重复的健康检查 HTTP 服务器** - BaseGameServer 内嵌 WebHost 已移除

### 🟠 P1 问题（本次修复）

#### §5.3 时钟偏差可配置性
- **问题**：`TokenSigner.GetAllowedSkewSeconds()` 硬编码返回 60，但文档称可配置
- **修复**：添加 `SetAllowedSkewSeconds(int seconds)` 公共方法
- **位置**：`src/Shared/TokenSigner.cs`

#### §5.4 RoundRobin 选择策略失效
- **问题**：每次请求都新建 `RoundRobinStrategy`，计数器无法跨请求保持
- **修复**：使用 `ConcurrentDictionary` 缓存策略实例为单例
- **位置**：`src/Core/Directory/ServerSelectionStrategy.cs`

#### §4.4 Redis SSL/mTLS 配置项接线
- **问题**：Redis SSL 配置项定义了但未生效
- **修复**：修改 `RedisServerRegistry` 构造函数，支持 SSL/证书配置
- **位置**：`src/Servers/DirectoryServer/RedisServerRegistry.cs`
- **位置**：`src/Servers/DirectoryServer/Program.cs`

### 🟡 P2 问题（本次修复）

#### §5.5 每连接限流的黑名单按 IP 记录
- **问题**：每连接限速触发时按 `IP:port` 拉黑，重连换端口后失效
- **修复**：将每连接限速的黑名单也改为按 IP (`remoteIpOnly`) 记录
- **位置**：`src/Core/BaseGameServer.cs` (第 465, 493 行)

#### §5.6 反射驱动的响应状态判定
- **问题**：依赖反射读取响应属性，脆弱且性能差
- **修复**：
  1. 创建显式响应契约 `IServerResponse` (`src/Core/IServerResponse.cs`)
  2. 创建 Protobuf 响应适配器 (`src/Core/ProtobufResponseExtensions.cs`)
  3. 修改 `HandlerInvoker` 优先使用接口，回退到反射
- **位置**：`src/Core/MessageHandling.cs`

#### §5.1 测试项目恢复
- **问题**：测试项目被整体删除，覆盖率归零
- **修复**：
  1. 恢复测试项目 `tests/Tests/Tests.csproj`
  2. 添加 `TokenSignerTests` 单元测试
  3. 将测试项目加入解决方案
- **位置**：`tests/Tests/`

```csharp
public static void SetAllowedSkewSeconds(int seconds)
{
    if (seconds < 0) throw new ArgumentOutOfRangeException(nameof(seconds), "时钟偏差不允许为负值");
    _allowedSkewSeconds = seconds;
}
```

### 2. RoundRobin 策略单例化
```csharp
private static readonly ConcurrentDictionary<string, IServerSelectionStrategy> _strategyCache = new();

public static IServerSelectionStrategy Create(string? strategy)
{
    var strategyName = (strategy ?? "load").ToLowerInvariant();
    return _strategyCache.GetOrAdd(strategyName, name => name switch
    {
        "random" => new RandomStrategy(),
        "round_robin" => new RoundRobinStrategy(),
        _ => new LoadBasedStrategy(),
    });
}
```

### 3. Redis SSL 支持
```csharp
public RedisServerRegistry(string connectionString, RedisRegistryOptions? sslOptions, int cleanupIntervalSeconds = 10)
{
    _configOptions = ConfigurationOptions.Parse(connectionString);
    
    if (sslOptions is { Ssl: true })
    {
        _configOptions.Ssl = true;
        _configOptions.SslProtocols = SslProtocols.Tls12 | SslProtocols.Tls13;
        _configOptions.CertificateValidation += (_, _, _, policyErrors) =>
            !sslOptions.ValidateServerCertificate || policyErrors == SslPolicyErrors.None;
        
        if (!string.IsNullOrWhiteSpace(sslOptions.ClientCertificate.Path))
        {
            var cert = new X509Certificate2(sslOptions.ClientCertificate.Path,
                sslOptions.ClientCertificate.Password);
            _configOptions.CertificateSelection += (_, _, _, _, _) => cert;
        }
    }
}
```
